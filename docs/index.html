Developer API

Axum REST Endpoints

Integrate Open Generative AI directly into Python, Go, Node, or shell scripts.

POST /api/v1/generate/image

Submit a text-to-image or image-to-image task and receive the completed asset URL.

curl -X POST http://127.0.0.1:8080/api/v1/generate/image \
  -H "Content-Type: application/json" \
  -d '{"model": "flux-dev", "prompt": "cyberpunk skyline", "aspect_ratio": "16:9"}'
POST /api/v1/workflows/run

Trigger a multi-step DAG pipeline (e.g. AI Influencer, Popcorn Storyboard) with variable passing.

curl -X POST http://127.0.0.1:8080/api/v1/workflows/run \
  -H "Content-Type: application/json" \
  -d '{"template_id": "ai-influencer", "inputs": {"prompt": "news anchor"}}'
